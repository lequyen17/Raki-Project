# 🚀 Raki Project - Hướng Dẫn Triển Khai Với Docker

Mở Terminal tại thư mục chứa file docker-compose.yml và chạy lệnh sau để Docker tự động tải các Image từ Docker Hub về và chạy ngầm:

sudo docker compose up -d

Giao diện người dùng (Frontend): http://localhost:3000

Hệ thống API (Backend): http://localhost:8000
